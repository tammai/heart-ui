Heart UI is a versatile and customizable UI library for Nuxt, delivered as a Nuxt layer for seamless integration. Built on top of Tailwind CSS and official Nuxt modules.

## Quick Start

Just add the Heart UI layer to your Nuxt project and you're good to go!

```typescript [nuxt.config.ts]
// nuxt.config.ts
// ...
extends: [
  ['github:tammai/heart-ui', { install: true }]
],
// ...
```

For full documentation including config theme, customize UI and so on, please visit https://heart.nuxt.dev
